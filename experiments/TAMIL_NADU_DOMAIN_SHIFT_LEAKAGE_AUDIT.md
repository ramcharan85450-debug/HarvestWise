## A leakage-adjacent limitation this audit CANNOT clear

Every check above concerns *information flow inside the pipeline*, and all of them pass. They say nothing about a separate problem that no amount of code discipline can fix: in this dataset **region and time period are perfectly confounded**. Andhra Pradesh and Telangana supply only 1999–2012; Tamil Nadu supplies only 2019 and 2024. There is no overlapping year, and no overlapping season label either (Kharif/Rabi vs Whole Year). Any AP+TG → Tamil Nadu result therefore measures geography *and* era *and* season definition together. This is a design limitation of the available data, reported here so that a clean audit is not mistaken for a clean causal claim.
